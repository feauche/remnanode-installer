# Remnanode Installer

Автоматическая подготовка сервера под **ноду Remnawave** «под ключ» одной командой:
закалка и защита сервера, установка самой ноды и команда управления **`nodectl`**.

Скрипт задаёт всего несколько вопросов в начале, а дальше делает всё сам — от firewall
и защиты от атак до поднятия контейнера ноды.

## Особенности

- **Всё в одной команде.** Спрашивает SSH-порт, секретный ключ и порт ноды, версию — и настраивает сервер без лишних вопросов.
- **Полная закалка сервера:** UFW firewall, миграция SSH-порта (с авто-откатом), Fail2Ban, hardening ядра, тюнинг сети и лимитов под тысячи клиентов, авто-обновления безопасности, анти-флуд (SYN/скан), Docker+UFW fix.
- **Установка ноды.** Ставит Docker и поднимает официальный контейнер `remnawave/node` (версия `latest` для панели 3+ или `2.8.0` для панели до 3 — на выбор) с ротацией логов.
- **Команда `nodectl`** — простое меню управления безопасностью и дополнениями (geoblock, IPv6/ICMP, SYNPROXY, Psiphon для Gemini, WARP Native, Selfsteal для Reality, удаление ноды).
- **Обфускация.** Служебные файлы получают непрозрачные имена (уникальные для сервера) — по ним труднее опознать ноду.

## Требования

1. Сервер на **Ubuntu или Debian** (нужен `root`-доступ).
2. Панель **Remnawave**, где вы добавляете ноду и получаете **Secret Key** и задаёте **Node Port**.

## Установка

Выполните на сервере (скрипт спросит SSH-порт, секретный ключ ноды и порт ноды):

```bash
bash <(curl -sL https://raw.githubusercontent.com/feauche/remnanode-installer/main/install.sh)
```

> ⚠️ **Важно:** `Secret Key` и `Node Port`, которые вы вводите, должны **совпадать** с тем,
> что заведено в панели при добавлении ноды (поле «Node Port» и сгенерированный секрет).

### Что спрашивает установщик
- **SSH-порт** — оставить текущий или сменить (при смене — миграция с авто-откатом, если что-то пойдёт не так).
- **Секретный ключ ноды** — из панели: `Nodes → Add Node → Secret Key`.
- **Порт ноды** — то же значение, что в поле «Node Port» панели (по умолчанию `2420`).
- **Версия ноды** — `latest` (для панели версии 3 и выше) или `2.8.0` (для панели версии до 3).
- **Логи ноды** — писать `access.log` и `error.log` в `/var/log/remnanode` с ротацией logrotate (50 МБ × 5, по умолчанию да) или оставить внутри контейнера. Позже это включается пунктом «l» в `nodectl`.

## Что делает скрипт (по шагам)

1. Обновление системы (`apt update && upgrade`).
2. **UFW** — установка firewall.
3. **Миграция SSH + правила UFW** — открывает только SSH и порт ноды; при смене SSH-порта переносит его с проверкой и авто-откатом.
4. **Fail2Ban** — защита от брутфорса SSH.
5. **Kernel Hardening** — sysctl-усиления против спуфинга/атак.
6. **Сеть, производительность и лимиты** — BBR + fq, буферы, `nf_conntrack`, лимиты дескрипторов под тысячи клиентов.
7. **Отключение IPv6** (если у сервера есть IPv4; иначе пропускается).
8. **Firewall: анти-флуд + ICMP** — дроп мусорных пакетов, per-IP лимит SYN, rate-limit ping.
9. **Авто-обновления безопасности + системные журналы** (`unattended-upgrades`, `journald persistent`).
10. **Установка Remnanode** — Docker + `/opt/remnanode/docker-compose.yml` + запуск контейнера.
11. **Docker + UFW fix** — заставляет Docker уважать firewall.

В конце устанавливается команда **`nodectl`** и показывается итог.

## Управление: команда `nodectl`

После установки на сервере доступна команда `nodectl` — интерактивное меню:

```
🔒 Безопасность
  1) Fail2Ban (баны SSH)
  2) Геоблокировка по странам (весь сервер — все порты)
  3) IPv6 вкл/выкл
  4) ICMP пинг вкл/выкл
  5) SYNPROXY (усиленная защита от SYN-флуда)

  6) Логи firewall

🖥️ Нода
  9) Xray-core (своя версия / дефолт)
  l) Логи ноды — файлы + ротация (access.log и error.log в /var/log/remnanode, logrotate 50 МБ × 5)
     и живые логи контейнера (docker compose logs -f)

📦 Установки (дополнения)
  7) Psiphon — обход RU-метки IP, чтобы работал Gemini
  8) Selfsteal — маскировка Reality (обёртка над selfsteal.sh)
  w) WARP Native — выход нужных доменов через Cloudflare WARP (интерфейс WireGuard «warp»)

  u) Удалить ноду (полностью)
```

- `nodectl` — открыть меню
- `nodectl status` — краткий статус (сервисы, ядро, состояние ноды)
- `nodectl restart` — перезапустить ноду
- `nodectl update` — обновить образ ноды (до тега из `docker-compose.yml`)
- `nodectl logs` — живые логи контейнера ноды: то же, что `cd /opt/remnanode && docker compose logs -f`; выход — `Ctrl+C`. Дополнительные параметры уходят в `docker compose logs`, например `nodectl logs --tail 100`
- `nodectl logs access|error [N]` — хвост файлов логов ноды из `/var/log/remnanode` (если включены)
- `nodectl logs-enable` — вывести логи ноды в файлы + ротация (то же, что пункт «l» меню)
- `nodectl update-self` — обновить только команду `nodectl` из GitHub (закалка, UFW и нода не трогаются)

Перезапуск, обновление ноды, статус и обновление скрипта есть и в самом меню
(пункты `r`, `n`, `i`, `s`), короткие команды дублируют их для скриптов и cron.

Прямо в меню видно текущее состояние: у геоблока/IPv6/ICMP — галочка/крестик,
у Psiphon/WARP/Selfsteal — «установлено / не установлено», у Xray-core — «из образа / вручную».

> ⚠️ **Геоблокировка** блокирует выбранные страны **на всех портах** — полностью
> закрывает сервер для этих стран. НЕ добавляйте туда страны своих VPN-клиентов
> (RU и IR в рекомендованный набор **не** входят).

### Дополнения (ставятся по желанию, требуют уже установленной ноды)
- **Psiphon** — поднимает локальный SOCKS5 для обхода RU-метки IP (чтобы заработал Gemini). Маршрутизация нужных доменов настраивается в конфиге Xray на панели.
- **Selfsteal** — веб-сервер-обманка для маскировки Reality (Caddy или Nginx). Пункт меню показывает готовый конфиг Xray для панели.
- **WARP Native** — ставит Cloudflare WARP как интерфейс WireGuard `warp` (без `warp-cli`, установщик [distillium/warp-native](https://github.com/distillium/warp-native)) с watchdog и kill-switch. Пункт `w` меню: установка, статус и проверка выхода, перезапуск, лог watchdog, удаление и готовые **outbound `warp-out` + правило routing** для конфига Xray на панели. Установщик WARP сам задаёт вопросы: язык, ключ WARP+ (Enter — пропустить) и интервал проверки (Enter — 5 минут). Перед удалением WARP уберите `warp-out` и его правило из конфига на панели, иначе трафик по этому правилу перестанет проходить.

## Обновление скрипта

Скрипт устанавливается «одним файлом» и обновляется повторным запуском той же команды:

```bash
bash <(curl -sL https://raw.githubusercontent.com/feauche/remnanode-installer/main/install.sh)
```

Повторный запуск **безопасен**: установщик видит уже стоящую ноду и **не трогает её**
(секретный ключ, порт и версия сохраняются), заново применяет идемпотентную закалку
и обновляет команду `nodectl` до свежей версии. Правила UFW при повторном запуске
**не сбрасываются**, добавленные вручную порты остаются. Спросит только SSH-порт —
нажмите Enter, чтобы оставить текущий.

Если нужно обновить **только команду `nodectl`** (без повторной закалки и без
касания firewall), с сервера: `nodectl update-self`. Под капотом это тот же
install.sh с ключом `--update-nodectl`.

## После установки

1. В панели Remnawave завершите добавление ноды (`Next → Config Profile → Create`).
2. Для маскировки Reality — установите **Selfsteal** через `nodectl` и добавьте показанный конфиг Xray в панель.
3. Порт ноды нужен только для связи с панелью — держите его закрытым для чужих (по возможности ограничьте по IP панели).

## Файлы

- Compose ноды: `/opt/remnanode/docker-compose.yml`
- Команда управления: `/usr/local/bin/nodectl`
- Конфиги firewall/ядра создаются с непрозрачными именами (обфускация).
