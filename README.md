# Remnanode Installer

Автоматическая подготовка сервера под **ноду Remnawave** «под ключ» одной командой:
закалка и защита сервера, установка самой ноды и команда управления **`nodectl`**.

Скрипт задаёт всего несколько вопросов в начале, а дальше делает всё сам — от firewall
и защиты от атак до поднятия контейнера ноды.

## Особенности

- **Всё в одной команде.** Спрашивает SSH-порт, секретный ключ и порт ноды, версию — и настраивает сервер без лишних вопросов.
- **Полная закалка сервера:** UFW firewall, миграция SSH-порта (с авто-откатом), Fail2Ban, hardening ядра, тюнинг сети и лимитов под тысячи клиентов, авто-обновления безопасности, анти-флуд (SYN/скан), Docker+UFW fix.
- **Установка ноды.** Ставит Docker и поднимает официальный контейнер `remnawave/node` (версия 2.8.0 или latest — на выбор) с ротацией логов.
- **Команда `nodectl`** — простое меню управления безопасностью и дополнениями (geoblock, IPv6/ICMP, SYNPROXY, Psiphon для Gemini, Selfsteal для Reality, удаление ноды).
- **Обфускация.** Служебные файлы получают непрозрачные имена (уникальные для сервера) — по ним труднее опознать ноду.

## Требования

1. Сервер на **Ubuntu или Debian** (нужен `root`-доступ).
2. Панель **Remnawave**, где вы добавляете ноду и получаете **Secret Key** и задаёте **Node Port**.

## Установка

Выполните на сервере (скрипт спросит SSH-порт, секретный ключ ноды и порт ноды):

```bash
bash <(curl -sL https://raw.githubusercontent.com/LumaxDev/remnanode-installer/main/install.sh)
```

> ⚠️ **Важно:** `Secret Key` и `Node Port`, которые вы вводите, должны **совпадать** с тем,
> что заведено в панели при добавлении ноды (поле «Node Port» и сгенерированный секрет).

### Что спрашивает установщик
- **SSH-порт** — оставить текущий или сменить (при смене — миграция с авто-откатом, если что-то пойдёт не так).
- **Секретный ключ ноды** — из панели: `Nodes → Add Node → Secret Key`.
- **Порт ноды** — то же значение, что в поле «Node Port» панели (по умолчанию `2420`).
- **Версия ноды** — `2.8.0` (стабильная) или `latest` (свежая).

## Что делает скрипт (по шагам)

1. Обновление системы (`apt update && upgrade`).
2. **UFW** — установка firewall.
3. **Миграция SSH + правила UFW** — открывает только SSH и порт ноды; при смене SSH-порта переносит его с проверкой и авто-откатом.
4. **Fail2Ban** — защита от брутфорса SSH.
5. **Kernel Hardening** — sysctl-усиления против спуфинга/атак.
6. **Сеть, производительность и лимиты** — BBR + fq, буферы, `nf_conntrack`, лимиты дескрипторов под тысячи клиентов.
7. **Отключение IPv6** (если у сервера есть IPv4; иначе пропускается).
8. **Firewall: анти-флуд + ICMP** — дроп мусорных пакетов, per-IP лимит SYN, rate-limit ping.
9. **Авто-обновления безопасности + системные журналы** (`unattended-upgrades`, `journald persistent`).
10. **Установка Remnanode** — Docker + `/opt/remnanode/docker-compose.yml` + запуск контейнера.
11. **Docker + UFW fix** — заставляет Docker уважать firewall.

В конце устанавливается команда **`nodectl`** и показывается итог.

## Управление: команда `nodectl`

После установки на сервере доступна команда `nodectl` — интерактивное меню:

```
🔒 Безопасность
  1) Fail2Ban (баны SSH)
  2) Геоблокировка по странам (только SSH)
  3) IPv6 вкл/выкл
  4) ICMP пинг вкл/выкл
  5) SYNPROXY (усиленная защита от SYN-флуда)

  6) Логи firewall

📦 Установки (дополнения)
  7) Psiphon — обход RU-метки IP, чтобы работал Gemini
  8) Selfsteal — маскировка Reality (обёртка над selfsteal.sh)

  u) Удалить ноду (полностью)
```

- `nodectl` — открыть меню
- `nodectl status` — краткий статус (сервисы, ядро, состояние ноды)

### Дополнения (ставятся по желанию, требуют уже установленной ноды)
- **Psiphon** — поднимает локальный SOCKS5 для обхода RU-метки IP (чтобы заработал Gemini). Маршрутизация нужных доменов настраивается в конфиге Xray на панели.
- **Selfsteal** — веб-сервер-обманка для маскировки Reality (Caddy или Nginx). Пункт меню показывает готовый конфиг Xray для панели.

## После установки

1. В панели Remnawave завершите добавление ноды (`Next → Config Profile → Create`).
2. Для маскировки Reality — установите **Selfsteal** через `nodectl` и добавьте показанный конфиг Xray в панель.
3. Порт ноды нужен только для связи с панелью — держите его закрытым для чужих (по возможности ограничьте по IP панели).

## Файлы

- Compose ноды: `/opt/remnanode/docker-compose.yml`
- Команда управления: `/usr/local/bin/nodectl`
- Конфиги firewall/ядра создаются с непрозрачными именами (обфускация).
